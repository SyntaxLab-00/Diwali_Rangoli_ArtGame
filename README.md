# 🪔 Diwali Rangoli Studio & Interactive Game

An interactive, browser-based festive art studio and mini-game collection built with vanilla **HTML5 Canvas**, **JavaScript**, and the **Web Audio API**. Zero dependencies, zero build steps—just open and celebrate!


## ✨ Features

- **🌀 Real-Time Kaleidoscope Symmetry:** Draw a single stroke and watch it mirror dynamically across **4, 6, 8, 12, or 16 radial axes**.
- **🎨 Festive Powders & Courtyard Floors:** Choose from **16 vibrant Rangoli powder colors**, 5 traditional floor themes (Midnight Temple, Terracotta Courtyard, Royal Velvet, Emerald Marble, Sandstone), and a toggleable **Kolam (*Pulli*) dot grid**.
- **🖌️ 8 Creative Brushes & Stamps:**
  - Textured Rangoli Sand Powder (*Gulal*)
  - Smooth Glowing Neon Lines
  - Marigold (*Genda*) Flower Petals
  - Lotus Stencils & Pearl Beads (*Moti*)
  - Sparkle Glitter & Animated Flickering Clay Diyas
- **🎮 4 Interactive Game & Studio Modes:**
  1. **Creator Mode:** Freehand digital Rangoli sandbox with undo history and custom greeting card export.
  2. **Trace Challenge:** Stencil-tracing game with pixel-accuracy scoring that rewards clean strokes and penalizes stray scribbles.
  3. **Diya Memory:** Musical light-and-chime sequence memory game around a ring of clay diyas.
  4. **Color Fill Puzzle:** Tap-to-fill geometric mandala coloring puzzle with procedural pattern generation and textured sand fills.
- **🎵 Synthesized Web Audio:** Native festive sitar/chime notes and celebratory firework effects generated procedurally—no external MP3 files required.
- **💌 Greeting Card Export:** Frame your finished Rangoli with a custom Diwali wish and download it as a high-resolution image to share.
